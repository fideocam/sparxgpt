# Example: motivation and strategy viewpoint

When the user asks for **motivation**, **goals**, **principles**, or **capability** mapping:

Typical elements: Stakeholder, Driver, Assessment, Goal, Outcome, Principle, Requirement, Constraint, Capability, Resource, CourseOfAction.

Typical relationships: InfluenceRelationship (driver/assessment → goal), RealizationRelationship (requirement → goal/principle; resource → capability). AssociationRelationship only if nothing tighter fits.

Do not drop ApplicationComponent onto a motivation view unless the user asked how an application realizes a requirement.
