# Asiakirjajulkisuuskuvaus (28 §)

The **asiakirjajulkisuuskuvaus** is a **public, shorter** description of how a person can request official documents: what case registers exist, how to apply, and main publicity/confidentiality lines. Guidance: **VM 2020:22**.

It is **derived from** the tiedonhallintamalli, not a replacement. Do not generate only a julkisuuskuvaus when the user asked for a tiedonhallintamalli.

## ArchiMate mapping

Optional `Grouping` named `asiakirjajulkisuuskuvaus` containing the public-facing processes and registers. Keep confidential stores **out** of that grouping.
